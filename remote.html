חיבור WhatsApp כמכשיר מרוחק

העמוד הזה הוא רק אשף חיבור. ההתחברות עצמה מתבצעת ב‑WhatsApp Web הרשמי.

1לחץ על הכפתור למטה ופתח WhatsApp Web.
2בחר Link with phone number / Log in with phone number.
3בחר ישראל והכנס את המספר שמופיע כאן.
4WhatsApp יציג קוד חד־פעמי בן 8 תווים.
5באייפון: WhatsApp → Settings → Linked Devices → Link a Device → Link with phone number instead → אשר והקלד את הקוד.
לעולם אל תמסור את קוד הקישור לאדם אחר. המכשיר המרוחק יקבל גישה לחשבון לאחר שתאשר אותו באייפון.
