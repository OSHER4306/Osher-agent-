# Codex Open Source Fund — application draft

**Project name:** HEB-SHIELD — Hebrew AI Security Benchmark

**GitHub:** https://github.com/OSHER4306/Osher-agent-/tree/main/heb-shield

**Short description:** HEB-SHIELD is a small open-source, offline-first defensive evaluation prototype for Hebrew-language prompt injection and social-engineering detection. The current release includes 12 synthetic, labeled examples and a deterministic rule-based baseline. It does not claim production readiness or model-level evaluation.

**How API credits would be used:** Expand the dataset to 500–2,000 independently reviewed Hebrew and mixed Hebrew-English examples; run repeatable controlled evaluations across documented OpenAI models; measure precision, recall, false positives and failure modes; publish reproducible aggregate findings and an open-source evaluation harness. Credits would be used only for authorized testing with synthetic, non-sensitive data.

**Current stage:** Early prototype. No third-party users, funding, independent validation or model evaluation claimed.

**Team:** Solo independent builder. Additional reviewers may be recruited later; none are claimed today.

**Requested support:** API credits for reproducible benchmark evaluations, amount subject to program rules and a documented evaluation budget.

**Applicant information:** Complete through official form using accurate legal name and email.
